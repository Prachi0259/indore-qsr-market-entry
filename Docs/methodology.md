# Methodology

## Market definition
The core market uses restaurant records classified as `Quick Bites` or containing `Quick Bites` in restaurant type.

## Branch definition
A branch is treated as:

`restaurant_name + locality + latitude + longitude`

This prevents repeated chain names from automatically being treated as duplicate branches.

## Proposition classification
Cuisine text is grouped into practical market propositions:
- Burgers / Fast Food
- Pizza
- Chinese / Momos
- Sandwich / Rolls / Wraps
- Biryani / Mughlai
- South Indian
- Indian / Regional
- Desserts / Bakery
- Cafe / Beverages
- Street Food / Snacks
- Other

## Price interpretation
The dataset measures approximate cost for two.

Brand X target AOV:
₹250–₹450 per person

Two-person proxy:
₹500–₹900

## Opportunity score
50% customer engagement + 30% supply whitespace + 20% price whitespace.

The score is relative within each proposition and is intended for prioritization rather than sales forecasting.

## Limitations
The source is a historical/public snapshot and should be validated against current market conditions before an actual investment decision.
