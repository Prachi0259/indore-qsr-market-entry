# Power BI

Power BI is the presentation layer for the SQL analysis.

## Dashboard Pages

### 1. Executive Market Overview
- market size
- QSR count
- ratings
- customer votes
- price distribution
- locality concentration

### 2. Competitive Landscape
- locality competition
- proposition mix
- engagement
- pricing

### 3. Opportunity Analysis
- locality × proposition opportunity score
- engagement vs whitespace
- competitive intensity
- target-price presence

### 4. Brand X Market Entry
- shortlisted locations
- shortlisted propositions
- price fit
- competitive context
- executive recommendation
